# 📖 About

Welcome to my DSA journey!

I started this repository to document every concept, problem, mistake, and solution while following **Striver's A2Z DSA Sheet**.

This repository is intended for:

- Beginners learning DSA
- Students preparing for placements
- Anyone looking for clean Java solutions
- People who want to learn the thought process instead of memorizing solutions

I will be solving every problem in **Java** and explaining the intuition, brute-force approach, optimized approach, and time & space complexities.
